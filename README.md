Name : Animal Shop 🐾

Purpose : 
A modern web application for browsing and purchasing animals, featuring secure user authentication and profile management.

Live url : https://assignment-8-lime.vercel.app


Key Features : 

    ```User Authentication: Secure Sign-up, Login, and Logout powered by Better-Auth.

    Profile Management: Dedicated profile page with the ability to update user name and photo via a custom modal.

    Dynamic Animal Listing: View all animals with real-time data fetching.

    Smart Sorting: Easily sort animals by price (Low to High / High to Low).

    Responsive Design: Fully mobile-responsive UI built with Tailwind CSS and DaisyUI.

    Protected Routes: Middleware integration to ensure profile pages are only accessible to logged-in users.```


    NPM Packages Used
Framework: next (Next.js 15+)

Authentication: better-auth

Styling: tailwindcss, daisyui

Icons: react-icons

HTTP Client: better-fetch

Database : MongoDb atlas
